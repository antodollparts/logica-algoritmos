# 📚 Módulo 2: Lógica y Algoritmos.

Este repositorio contiene los proyectos y ejercicios prácticos desarrollados a lo largo del módulo 2, organizados por nombre de clase/proyecto.

---

## 📖 Contenido del Curso

### Clase 1 — Introducción a ECMAScript
> Fundamentos del estándar ECMAScript y las características modernas de JavaScript.

- Variables: `let`, `const` vs `var`
- Arrow functions
- Template literals
- Módulos ES6 (`import` / `export`)

---

### Clase 2 — Estructuras de Datos
> Estructuras de datos esenciales implementadas con JavaScript moderno.

- Arrays y objetos
- Sets y Maps
- Pilas (Stacks) y Colas (Queues)
- Listas enlazadas

---

### Clase 3 — Métodos de Arreglos
> Uso de los métodos funcionales de los arreglos en ES6+.

- `map()`, `filter()`, `reduce()`
- `find()`, `findIndex()`, `some()`, `every()`
- `flat()`, `flatMap()`

---

### Clase 4 — Algoritmo de Los 2 Punteros
> Técnica de los dos punteros para resolver problemas de arrays y cadenas de forma eficiente.

- Concepto del patrón Two Pointers
- Problemas de suma de pares
- Inversión de arreglos y strings

---

### Clase 5 — Algoritmo Sliding Window
> Técnica de la ventana deslizante para optimizar recorridos sobre secuencias.

- Ventana de tamaño fijo
- Ventana de tamaño variable
- Problemas de subcadenas y subarreglos

---

### Clase 6 — Recursión y Backtracking
> Resolución de problemas mediante llamadas recursivas y retroceso.

- Fundamentos de la recursión
- Casos base y casos recursivos
- Backtracking aplicado a permutaciones y combinaciones

---

### Clase 7 — Divide y Vencerás
> Estrategia algorítmica de dividir el problema en subproblemas más pequeños.

- Merge Sort
- Binary Search
- Quick Sort

---

### Clase 8 — Introducción al Manejo de Archivos con Node.js
> Lectura, escritura y manipulación de archivos usando el módulo `fs` de Node.js.

- Módulo `fs` (File System)
- Lectura y escritura síncrona y asíncrona
- Manejo de rutas con `path`

## 🚀 Cómo Ejecutar los Proyectos

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/curso-ecmascript.git](https://github.com/antodollparts/logica-algoritmos.git
   ```

2. Entra a la carpeta que deseas explorar:
   ```bash
   cd nombre-proyecto
   ```

3. Ejecuta el archivo con Node.js:
   ```bash
   node nombre-archivo.js
   ```

> **Nota:** Asegúrate de tener [Node.js](https://nodejs.org/) instalado (v14 o superior recomendado).
